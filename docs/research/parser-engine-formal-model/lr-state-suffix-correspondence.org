* Paper semantics and the implementation boundary

[[https://www.deinprogramm.de/sperber/papers/lr-essence-pepm.pdf][The Essence of LR Parsing, section 2.2]] defines prediction from an item
=A -> alpha . B beta (rho)= to =B -> . delta (sigma)= using
=sigma in FIRST(beta rho)=. Closure includes transitive predictions. Goto
advances the dot over the selected symbol while retaining its lookahead.
FIRST describes a reachable terminal prefix; the remaining suffix need not
have a complete terminal derivation.

These are three different responsibilities: LR0 core provenance, suffix
lookahead meaning, and the physical representation of published item rows.
Production equality in this relation is semantic equality; native production IDs
remain a separate correspondence obligation. An LR0 core appearing in a closure does not by itself establish any LR1
lookahead, and merged LALR states are not claimed identical to canonical LR1
states. The proofs below preserve these distinctions.

* Completed facts to every suffix

[[file:../../../formal/ParserEngine/SuffixSemantics.lean][SuffixSemantics]] uses name-level FIRST and nullable facts. Its
=from_completed_exact= consumes the existing nullable and FIRST solver
histories and their empty pending queues. Name-level semantic equivalence is
derived from =Solver.preparation_pipeline_exact=, not provided as a final
per-suffix certificate.

=scan_exact= proves both directions for an arbitrary RHS. A terminal resets
FIRST to its singleton and nullability to false. A nonterminal contributes
its name-level FIRST, unions the tail only when nullable, and conjoins the
two nullable flags. The completed suffix has mask zero and nullable true.
An empty FIRST mask alone does not imply nullability.

=execute_exact= and =reverse_execution= follow the backward accumulator loop:
starting with the completed suffix, consume one preceding symbol and publish
one row per step. They derive the complete catalogue from this execution.
=catalogue_at= relates any valid dot to the corresponding dropped RHS;
=packed_at= adds all preceding production widths plus their completed slots.
Thus zero-width productions still occupy one valid slot and cannot alias the
next production's first slot.

* Core closure and ordered publication

[[file:../../../formal/ParserEngine/LRStateSemantics.lean][LRStateSemantics]] defines production prediction by the actual
leftmost-symbol ancestry: seed a rule owned by the requested nonterminal,
then follow only the first RHS symbol of an already predicted production.
=closure_exact= derives the kernel-or-transitive-template decomposition for
arbitrary grammars, including cyclic prediction ancestry.

The source =lr0-closure= consumes increasing kernel and prediction item rows
while accumulating the processed prefix in reverse. Gerbil's
=(foldl cons tail found)= uses =tail= as its initial accumulator. The
=foldl_cons_tail= and =merge_accumulator= proofs establish that this restores
the processed prefix before the retained suffix, preserving output order.
=union_member= and =merge_member= establish exact membership, and
=closure_merge_sorted= derives strict output ordering from strict input rows.
Overlap between kernel and predictions does not introduce a duplicate.

=decoded_closure= composes this physical merge with core decoding and the
prediction template relation. Its =templateExact= premise remains explicit:
this theorem does not claim that the native mutable prediction-mask solver
has already been refined to the transitive production relation.

* Prediction and goto composition

=compiled_prediction= replaces the former per-suffix FIRST/nullable
soundness premises with =SuffixSemantics.scan_exact=.
=completed_prediction= composes this result with completed solver histories.
The remaining lookahead decoding premises distinguish inherited EOF from
ordinary terminal keys; no theorem asserts that every set bit denotes an
ordinary terminal.

=physical_goto= uses the actual production row and after-dot symbol read to
compose the dense =core + 1= operation with =Grammar.Advances=. The read
excludes completed slots and preserves the selected lookahead, including EOF.

* Complete propagation ancestry

[[file:../../../formal/ParserEngine/PropagationSemantics.lean][PropagationSemantics]] composes every finite lookahead propagation ancestry
with state-indexed paper prediction and goto histories. =reach_supported=
handles shift, inherited nullable evidence and first activation. No semantic
lookahead certificate is supplied for each final bit. =replay_supported=
uses successful FIFO replay and queue exhaustion from the existing operational
solver proof to derive the same provenance for every published known bit.

The =Coordinates= adapter keeps parser-owned premises visible: physical node
to state/core/suffix mapping, terminal-key decoding, closure target shape and
actual transition edges. Its FIRST/nullable meaning comes from the new suffix
proofs. This is a universal composition theorem under producer correspondence,
not a claim that all native LR0 construction or coordinate extraction is proved.

=compiled_suffix= connects the actual generated graph read at =core + 1=
through =SuffixSemantics.after_dot_read= to paper FIRST/nullable meaning at
=RHS.drop(dot + 1)=. It excludes completed parent items using the after-dot
bound. =extracted_supported= composes the complete source-shaped graph builder
and FIFO witness checker with the state-indexed paper provenance theorem.
