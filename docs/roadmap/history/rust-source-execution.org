** Loader fixture metadata convergence

fixture status derivation and identity indexing move fully into the Loader.

Test strategies and benchmark corpus preparation use the shared Loader APIs.

metadata algorithms and authoring constraints; it makes no parser speed claim.

five-second idle deadline and termination. Seven remaining standalone Scheme

only after all output ports close. No timeout or compiler selection changes;
generation/formatting must retain byte-exact checked Rust products.

** Shared Command and Source execution boundary

The ordered constructor baseline =e1252ed102a1d67f5d2d1fb3ab359f6b7f97aed6=
passes Rust and Ubuntu CI. This change adds the shared closed Command interpreter
and the engine-owned Source cursor; =languages/= retains only declaration
interfaces. One admitted POO source strategy emits a single Rust Source product,
and a prepared Rust engine reuses scanner/Word/Command/result admission.

Literal/fallback selector preparation follows Scheme precedence. Command
control uses explicit frames/tasks and checks loop progress. Source construction
covers all 14 production forms, arrays, descriptor/redirection spans, pipelines,
and-or lists, deferred bodies and complete trivia publication. Shared call-DAG
admission computes widths once in topological order, with a 32-level double-call
control that does not expand exponentially. Unicode keywords, root projection,
pipeline role and empty-prefix POO overrides use the identical engine.

The independent Scheme generator publishes 54 full-Source controls, including
rejection outcomes. Rust compares full Rust syntax events, field sequence, FIFO
marker/body links and source roundtrips. The public generated product API and
the token-tape API both run these controls. Invalid tape, wrong catalog and
cyclic/nullable/ambiguous declarations are rejected explicitly.

This closes standalone Command/Source recognition for the qualified corridor.
Full versioned ParseArtifact identity/hash/diagnostic parity and binding that
Rust Source product through the language-independent native ABI remain open.
The remaining recursive Source command/list bridge has a 256-level rejection
gate; an explicit Source task stack is still needed for unbounded nesting.
The loader v2, Source v1, native metadata v1 and language handle ABI v2 remain
unchanged. Qualification is semantic/structural evidence, not a parse-speed claim.
