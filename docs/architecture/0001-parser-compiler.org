#+title: RFC 0001 — Pure Gerbil Parser Compiler Architecture
#+startup: overview

* Status

Accepted.  This RFC defines the implemented v1 compiler and runtime ownership
boundary.  It is a feature contract, not an execution plan.

* Authority

=gerbil-parser= is a pure Gerbil Scheme project.  =src/= owns only the
language-neutral grammar algebra, AOT compiler, generated-machine support, and
lossless runtime.  Versioned grammars, fixtures, and tests live under
=languages/<language>/<version>/=.  POO Flow roles may compose a grammar before
the canonical boundary, but POO, grammar normalization, and parser-table
construction are absent from the runtime closure.

#+begin_src mermaid
flowchart LR
  D[Hygienic language declaration] --> G[Grammar IR v1]
  S[Pinned native grammar and digest] --> X[Expansion-time source macro]
  X --> G
  G --> L[Deterministic LALR analysis]
  L --> F[Explicit selective GLR actions]
  F --> I[Parser IR v1]
  I --> A[AOT native machine]
  B[Source bytes] --> A
  A --> P[ParseArtifact v1]
  P --> C[Lossless CST projection]
#+end_src

* Formal contract

Macro expansion is the sole table-publication boundary.  Runtime parsing reads
an immutable generated machine and publishes exactly one accepted or rejected
ParseArtifact.  Failed selective branches do not mutate or publish partial CST
state.

#+begin_src typst
#let D = $"Declaration"_1$
#let G = $"GrammarIR"_1$
#let I = $"ParserIR"_1$
#let M = $"NativeMachine"_1$
#let A = $"ParseArtifact"_1$
$
  "expand": D -> (G, I, M) \
  "runtimeTableBuilds"(M) = 0 \
  forall s in "Source", "parse"(M, s) in {"accepted"(A), "rejected"(A)} \
  "accepted"(A) => "coveredBytes"(A) = [0, "sourceBytes"(s)) \
  "failedBranch" => "publishedPartialState" = 0
$
#+end_src

* Build and entry boundary

=build.ss= discovers Gerbil modules and owns AOT staging.  A language's
=grammar.ss= contains one declaration that generates grammar, parser IR,
machine, and descriptor bindings.  Its =parser.ss= contains only the public
=deflanguage-parser= entry.  Tests live under =t/= or beside a versioned
language pack and benchmarks use the ASP Gerbil Scheme benchmark API.

The repository owns no Rust, Rowan, language-specific AST, semantic-analysis,
or backend authority.  Downstream systems consume ParseArtifact v1.  =gparse=
is a thin command adapter over the same public Scheme parser API; it never owns
grammar or parser implementation.
