The integrated argument is: author declarations select one effective grammar;
analysis establishes facts about that grammar; each target checks its own
obligations; generated execution and artifact publication preserve the selected
meaning. A legal LR grammar need not satisfy a predictive target's proof. Target
failure must report the unsupported obligation rather than change CFG choice
into prioritized choice or silently substitute another backend.

* Qualification of the nullable algorithm slice

=de8bef5= replaces whole-production nullable rescans with occurrence dependencies.
For P productions and R rhs occurrences, expected constant-time table operations
give O(P + R) graph construction and propagation. Each nullable name publishes
once and each registered occurrence is discharged once. The public ordered list,
lookup membership and selected-origin repetition diagnostics retain their contract.

Local qualification completed 355 compiled semantic Cases across 23 groups and
17 source-mode canonical LR reference Cases. The resolved grammar Suite includes
512 cyclic grammar combinations against an independent repeated-scan oracle,
marked operands, terminal blockers, duplicate occurrences, first-lhs ordering and
a 4096-name reverse chain. Complete TLA+ LRSpec equals the pre-change snapshot.

Ten real TLA+ complete construction samples had CPU medians 15.068 ms before and
14.868 ms after, with no in-call GC. This difference is insufficient to claim
end-to-end acceleration. It does not measure Rust execution, FFI or incremental
parse latency. Latest delivered-head CI is a separate gate; inspect the PR check
for that exact SHA before treating a local receipt as remote closure.

Each item must define the existing engine owner, semantic consumer, negative
control and measurement boundary before adding a new abstraction. POO remains
the public extension mechanism where values are extensible; private algorithm
state uses named functions and compact records. No new loader schema or public
compatibility mode follows from this research sequence.

* Compiled declaration-test host contract

Declarative syntax/source checks must not turn input AST depth into native call
stack growth. Their engine-owned inspection uses explicit frames with lexical
port authority; language authors add neither traversal nor output exceptions.
Deep rejection, legal fixture capture and shadowed-port controls exercise the
same compiled semantic entry used by CI.

Large expanded test objects retain the immutable SDK's optimizer and tail-call
contract. Their builder selects Gambit's per-procedure C hosts, preventing one
expanded Suite from becoming a giant C optimization unit. Production objects
retain SDK defaults. Effective object options participate in
cache reuse, with success-only Scheme identity records. Full preparation still
proves the source/SDK closure. See the [[file:dsl-effective-grammar-admission.org][admission study]] for Ubuntu stack evidence,
rejected alternatives and delivered-head qualification limits.

* Completed FOLLOW graph facts and state-local accumulation

After quotient refinement, static block labels and shift-source membership are
indexed once by the engine. DFA target rows are local to one construction,
reused across states and cleared only at touched labels. Full closed state
identity and reduce/lookahead publication remain unchanged; first-seen labeled
transition order determines the same state numbering. Language loaders contribute
grammar values through their existing POO contract.

Performance admission compares the entire target LRSpec and includes indexing,
analyses and publication. Actual completed-state/item output is available through
the existing LR trace switch for long constructions. See the [[file:dsl-effective-grammar-admission.org][admission study]]
for the real TLA+ phase counts, exact-output A/B, cost limits and independent
compiled/source controls.
