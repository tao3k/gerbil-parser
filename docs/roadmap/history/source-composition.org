#+title: Historical source composition receipts

This module preserves prior design and qualification records. Its status notes
are historical; the active execution plan is [[file:../0001-versioned-language-pack-closure.org][the convergence plan]].

** Structured local lexemes — closed shared execution

TLA+ identifier, proof-start and proof-reference no longer publish external
callbacks. =run-containing= checks maximal runs and a required character class
in one traversal; =ends-in= and =ends-not-in= constrain the consumed span without
rescanning its body. These operations are general lexical IR, with Scheme and
Rust admission, preparation and execution. Their spelling and character classes
participate in the grammar digest. The module scanner macro now binds only the
remaining contextual module-text scanner; obsolete local callback exports are
removed, without aliases.

Rust alphabetic classification is generated from the pinned Scheme
=char-alphabetic?= predicate, just as numeric classification already is. The
portable witness imports the actual TLA+ fragments, emits a standalone parser,
and checks Unicode endpoints at nonzero offsets. This witness establishes local
lexical portability; it does not establish standalone full SANY execution.

The remaining closure sequence is explicit: prepare HL7 header and TLA+ nesting
context once (S2), lower shell command/word recognition into shared IR (S3),
replace the closed HCL recursive corridor with general lowering (S4), and publish
proof policy as portable data consumed by native C/Rust (S5). No runtime speedup
is asserted without complete-call matched measurements.

** Source preparation — header captures

The machine now lowers a distinct header capture plan once. Scheme and Rust
prepare valid and invalid header captures once per parse request. Scheme scope
restoration and parallel requests, Rust borrowed source ownership, and nested
lexical choices have explicit semantic controls. Incremental resume starts a
fresh source scope and retains existing runtime/checkpoint ownership. Record
projection consumes the same canonical header scanner module; the old scan
module forwarding exports are removed. No speedup percentage is claimed from
algorithmic work-count reduction alone.

** Source preparation — module framing

All TLA+ lexical roles now use closed IR. The old module scanner profile/binder
and its public macro are removed without aliases. =module-text= contains bounded
framing values; the shared engine prepares header intervals and nesting events
once per request. Long border runs do not expand into per-position records.
Scheme and standalone Rust share lexical admission, source ownership and emitted
values. Pinned Scheme whitespace joins alphabetic/numeric character authority.

Local controls cover exact endpoints, every offset against the prior framing
algorithm, nested comments/strings, an independent UNIT spelling, numeric extra
name characters, long borders, ordinary parser roundtrip and malformed profiles.
The complete TLA+ pack suite remains a required semantic gate. CI checks exact
regeneration of the standalone framing parser and whitespace table.

Header capture and module framing preparation are implemented. S2 remains open
for Bash source state; S3 command/word IR, S4 general recursive lowering and S5
portable proof policy still require implementation and real consumer gates.
No complete-call speedup is claimed from the indexing change alone.

Local module-framing receipt: 73 Scheme cases passed with explicit =OK= and
zero harness return; 102 Rust syntax tests plus the complete Rust workspace passed.
ASP Rust policy and Clippy passed. The GCC native generator built and its actual
executable emitted the same module parser as the Scheme producer. Exact parser
and whitespace-table regeneration passed. These are local results; exact PR-head
Ubuntu/Rust CI is a separate publication gate. Source-backed Rust tests live in
=tests/unit=, with explicit imports and =#[path]= mounts.

and node projection values. =defcommand-profile= constrains the grammar

** Control-program migration

The =forms= slot of =CommandProfile.= now owns all compound control grammar.
The old if, loop, iteration, case, function, conditional, arithmetic, group
and array functions are removed in favor of one closed program executor.
Literal dispatch, bounded lookahead, field checks, reference/cycle checks and
consuming-loop admission are engine capabilities. Pipeline header FIRST sets
avoid running nullable programs for ordinary commands. Source identity includes
the owned forms without changing Source v1, Loader v2 or C ABI v2.
Independent Unicode loop declarations and empty inherited prefix programs
exercise POO override semantics. No former execution path or macro compatibility
mode is kept. Complete Rust control/Word execution remains open.

The module-source generator previously printed its completion marker but
failed the five-second inactivity gate while exiting on macOS. It now flushes
and uses the existing finite-child normal exit binding. Local bounded native
regeneration exits zero in 8.22 seconds and matches the Rust artifact byte for
byte after formatting; neither timeout nor compiler selection changes.
