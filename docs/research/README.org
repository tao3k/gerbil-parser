#+title: Parser research

Research documents explain algorithm choices and their relation to the public
Grammar/Parser/Scanner IR. Executable correctness belongs in Scheme test suites;
performance admission belongs in the ASP =benchmark.ss= contracts.

Use the repository's native harness and existing =Justfile= entries. Keep
workloads, samples and thresholds in their Scheme owners. Research documentation
has no generated result snapshots, separate JSON report schemas, source-rewriting
instrumentation or runtime-binding replacement wrappers.

The paper/framework synthesis remains in
[[file:scheme-parser-performance-framework.org][scheme-parser-performance-framework.org]].

For the current Gerbil source study and the ordered runtime work, read
[[file:shared-scanner-staging-and-fusion.org][shared engine specialization, source spans and fusion]]. It separates
implemented preparation from proposed fusion and preserves negative receipts.

Language authoring research, annotated papers and proposed experiments are in
[[file:scheme-language-pack-design.org][Scheme language pack design]]. The document distinguishes the current
authoring interfaces from unimplemented research proposals.

The deeper [[file:scheme-language-pack-semantics.org][binding, field semantics and author task study]] develops namespace
policies, conservative count equations and concrete HCL/arithmetic examples.

The executable [[file:scheme-macro-binding-experiments.org][Gerbil macro binding experiments]] compare preserved definition
references, caller parameters and contextual reconstruction across modules.

The local [[file:scheme-poo-language-components.org][Scheme syntax and POO component study]] connects existing grammar roles
and explicit composition with expression/list vocabulary and compiler phases.

The local [[file:scheme-rule-context-design.org][rule-context declaration study]] checks how a rule can supply its own
identity once, with imported macro renaming and actual parser-event controls.

The local [[file:scheme-list-role-composition.org][multi-rule list and POO composition study]] checks transparent per-item
fields, deterministic helper identities and an explicit expansion-phase provider.

The local [[file:scheme-component-provenance.org][component provenance and admission study]] reuses existing Bound IR
inputs and checks which identities change when origins or composition metadata change.

The local [[file:scheme-composition-history.org][override and removal history study]] distinguishes effective declaration
origins from retained contributions, with parser/binding admission controls.

The local [[file:scheme-source-origin-contract.org][reader source-origin study]] distinguishes macro definition and component
invocation, with exact token-coordinate controls and retained timeout receipts.

The local [[file:scheme-declaration-diagnostics.org][declaration diagnostics study]] checks typed parameter errors, real-reader
coordinates and explicit unknown origins for source-free syntax.

The local [[file:scheme-nested-declaration-context.org][nested declaration-context study]] checks source-preserving wrappers and
renamed imports, while distinguishing parameter location from outer author context.

The local [[file:scheme-syntax-parameter-context.org][official syntax-parameter context study]] checks delegated author context,
scope isolation and declaration-versus-expression boundaries with real POO roles.

The current [[file:dsl-engine-contracts.org][DSL and engine contract audit]] connects choice semantics,
resolved grammar analysis, Source continuations and scanner state to AOT/FFI
admission, with an ordered implementation and qualification plan.

The focused [[file:scheme-source-edit-sessions.org][Source edit-session study]] defines the shared Scheme/Rust
lexical reuse boundary, owned history and complete-recognition controls.
