* Parser development ownership

=gerbil.pkg= pins ASP for development only. Run =just prepare-dev= and
=gerbil build=, then =just check-policy=. Gerbil runs the ASP policy suite against the same
=init.exports.std-make-spec= used by the root =build.ss=.

=rust-runtime-aot.ss= declares the optional Rust generator for the separate
root build entry. The production library spec does not install that executable.
