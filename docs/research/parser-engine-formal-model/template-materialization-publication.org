#+title: Generated prediction witnesses and published closure rows

* Paper, source and model responsibilities

[[https://www.deinprogramm.de/sperber/papers/lr-essence-pepm.pdf][The Essence of LR Parsing]], Section 2.2, distinguishes prediction, closure
and goto. The previous correspondence required a final =templateExact= premise.
This topic replaces that premise by composing name discovery, completed FIFO
execution, production-ID mask aggregation, dot-zero materialization and closure
merge. Transition publication then assigns persistent IDs to those closure rows.
No runtime performance optimization is part of this work.

| Implementation owner | Universal model responsibility | Native qualification |
|----------------------+--------------------------------+----------------------|
| Name discovery loop | First-occurrence index and RHS coverage | Recorded item-node IDs, including zero |
| Prediction propagation | Generated dequeue witness, exact exhaustion | Six unchanged native producer executions |
| Template and cache | Physical dot-zero projection and cache history | Whole template/cache declarations, sparse/full group comparison |
| State targets | Persistent target lookup and closure row meaning | Complete builder declaration, recursive and growing automata |

* Constructed inputs and generated witnesses

[[file:../../../formal/ParserEngine/NameDiscovery.lean][NameDiscovery]] interns the grammar's nonterminal symbol stream from an
empty registry. It proves the name-index law and RHS coverage from that history.
Completed physical slots contribute no name; filtering them preserves the exact
discovery stream. These facts discharge the local name assumptions of the
constructed grammar factory, rather than becoming final semantic certificates.

[[file:../../../formal/ParserEngine/PredictionWitness.lean][PredictionWitness.execute]] records each actual FIFO front while executing
the proved queue transition. Its termination measure is the catalogue-derived
finite rank. Its result contains the dequeue sequence, successful replay and
an exhausted final queue. =generated_exact= derives grammar prediction meaning
without a caller-supplied dequeue sequence or final-mask correctness assertion.

The same module checks raw observations separately: replay the recorded sequence,
require exhaustion and compare the physical mask vector. [[file:../../../formal/ParserEngine/PredictionObservation.lean][PredictionObservation]]
also compares the returned per-core catalogue with the recorded item-node map.
A false item-node slot publishes zero; integer node zero is a valid lookup.
Its soundness theorem applies to arbitrary decoded records.

[[file:../../../t/fixtures/prediction-witness.ss][The native recorder]] executes the unchanged complete prediction producer.
It forwards real queue/vector primitives, copies initialization values at the
first dequeue and records the native returned catalogue. The existing source
witness generator serializes those observations into fresh =SourceData=.
Lean checks all six records and rejects a changed first dequeue. These finite
receipts qualify the recorder; they do not prove arbitrary Scheme execution.

* Materialization and cache ownership

[[file:../../../formal/ParserEngine/PredictionMaterialization.lean][PredictionMaterialization]] aggregates the completed masks for every
kernel core. Each selected physical production ID becomes that production's
dot-zero dense offset. The universal template theorem derives exactly the
paper's transitive prediction relation. Its closure theorem composes the
materialized template with the existing ordered merge; =templateExact= is no
longer an input to this composed entry point. Equal grammar productions at
different IDs retain distinct physical offsets.

[[file:../../../formal/ParserEngine/TemplateCache.lean][TemplateCache]] starts empty for one fixed factory and preserves its
invariant after every lookup/publication. A history derives correctness of
cache hits; it does not assume that the final cache already has correct values.
The grammar/layout captured by that factory stays fixed for its lifetime.

[[file:../../../formal/ParserEngine/LRTemplateSource.lean][LRTemplateSource]] independently admits the complete native template
constructor and nested =template-for= declaration. Its source-checked closure
entry composes these schemas with generated prediction execution.

* Transition publication and concrete row factory

[[file:../../../formal/ParserEngine/TransitionPublication.lean][TransitionPublication]] models each group's kernel interning and final
row publication. Existing target IDs survive all subsequent appends. The final
row has exactly the input symbol order; every recorded target ID is the final
registry's ID for that group's kernel. Queue draining preserves storage,
uniqueness and processed/pending accounting. The accumulator proof matches the
source's single final reversal.

[[file:../../../formal/ParserEngine/PublishedClosure.lean][PublishedClosure]] instantiates the pointwise factory with the completed
prediction/materialization/merge chain. It derives grammar closure meaning for
every published target row. Raw kernel masks must stay inside the physical
layout domain; =KernelBound= makes this representation obligation explicit.
The discovered-factory theorem also supplies name-index and coverage proofs.
[[file:../../../formal/ParserEngine/LRTransitionSource.lean][LRTransitionSource]] independently checks the complete native builder,
including initialization, cache capture, growth, target selection, queue updates
and final transition-vector publication.

* Remaining correspondence boundary

The restricted source schemas identify supported idioms; they are not a general
Scheme interpreter. The subsequent [[file:physical-sparse-goto.org][physical extraction and sparse goto composition]]
derives physical symbol discovery, group membership, goto meaning and kernel
bounds. It records the remaining sorting, scratch and native control-flow
obligations separately. Host/compiler behavior stays external. Gambit is neither
modified nor built.
