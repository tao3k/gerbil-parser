=grammars=, =metadata=, value =fixtures= and named =tests= services through

Domain projections, pinned sources, fixtures and generated artifacts have
legitimate language ownership. File count alone is not a convergence gate.

with =declare-language-fixture-test= declarations bound to the descriptor.

explicit input/result contracts and POO admission.
Additional language assertions continue through native Scheme/ASP test suites.

Work proceeds by engine capability, migrating every applicable pack together.
A stage closes only after production callers migrate and obsolete callbacks or
assembly paths are removed. Moving an old callback into =src/= alone does not
close a stage. S4 can proceed alongside S2/S3; it does not wait for Bash full
syntax. SANY portable proof policy does not block ordinary lexical lowering.
