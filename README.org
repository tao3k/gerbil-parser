#+title: gerbil-parser
#+language: en

Gerbil Parser is a programmable syntax engine for Gerbil Scheme. Define a
grammar with Scheme macros, compose language services with POO, and parse into
source-preserving syntax artifacts. Generated Rust parsers and a C ABI provide
integration paths for other hosts.

The repository includes Arithmetic, Bash, Cypher, FHIRPath, GQL, HCL, HL7, and
TLA+ packs. Each pack documents the syntax and backends it qualifies.

* Build and test

From a checkout with Gerbil and its C toolchain on your path:

#+begin_src sh
gerbil deps --install
gerbil build
just test-all
cargo test --workspace --all-features --locked
#+end_src

The Scheme acceptance entry prepares its declared fixtures and runs the full
source suite. See the [[file:docs/architecture/qualification.org][qualification guide]] for host prerequisites, focused
checks, and generated-product verification.

* Use a language pack

For example, a Gerbil module can call the arithmetic parser:

#+begin_src scheme
(import (only-in :gerbil-parser/languages/arithmetic/parser parse-arithmetic))
(parse-arithmetic "1 + 2")
#+end_src

See the [[file:languages/README.org][language pack guide]] for grammar declarations, loader composition,
and fixtures. The [[file:docs/architecture/0003-parse-artifact.org][parse artifact contract]] defines the result boundary.
