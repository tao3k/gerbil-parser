#+title: Native line declaration compilation ownership

* Engine boundary

=src/modules/parser/interface.ss= exports admitted POO line declarations
and pure native event projections. =line-event-funs.ss= owns table row
splitting/escape and paragraph lifecycle; =inline-link-event-funs.ss= owns
link candidate state, bounded recognition and event commit. They lower into
the existing Scheme event-fold algebra, not a second evaluator or Rust parser.
No Org node, marker, helper name or runtime configuration belongs here.

=source-boundary-types.ss= and =source-boundary-objects.ss= admit POO
boundary queries and parent bindings. =source-boundary-funs.ss= composes
literal and source-named parents through the existing cached native future
queries. Languages declare closing markers, name-field bindings and heading
policies; they do not supply raw query callbacks or rebuild parent dispatch.
Unknown parent identifiers cannot admit a child. Duplicate identifiers,
incomplete name bindings and unsupported literal boundary policies are
rejected rather than silently changing semantics. Fixed queries currently
require case-insensitive markers, text recovery and a heading boundary;
named queries independently declare case, indentation, suffix and heading
policies. This does not implement a new scanner or remove domain frame state.

Language consumers supply node/token roles, lexical byte policies, named
content helpers and explicit helper parameter names. These bindings are data,
not raw callback forms. An invalid link target can recover its current span
or disable recognition for the remaining region. The latter is an explicit
Org choice, not the engine default. Opening-marker bytes are skipped before
separator recognition; committed closing bytes cannot be consumed twice.

* Rule-instance ownership

All three projections now require an admitted SourceEventScope with an
explicit rule-instance owner. Private state and table loop identifiers are
allocated by the engine from UTF-8 hexadecimal owner/role components. The
result is deterministic, delimiter-safe and valid through Rust identifier
projection; punctuation normalization cannot merge two owners. Reusing an
owner intentionally refers to the same instance. Independent instances must
declare different owners; there is no global counter, default legacy scope,
runtime registry or blanket symbol/tree rewrite.

The link projection also requires explicit index/cursor bindings from the
surrounding scanner. Named helper parameters are external bindings and are
not renamed when they match a private role. Paragraph span/blank transitions
and open predicates are named engine projections; consumers need not know
their private state slots. Existing request/helper frames still own execution
and lifetime. This slice does not admit an arbitrary whole-program scope
assembler or prove every remaining Org helper's recursive lifetime.

* Evidence and remaining work

=just test-line-events OUTPUT LOAD_PATH= compiles the changed engine owners
and runs four native suites from =t/=. The regular native test catalog already
discovers those suites; no duplicate CI lane or independent runner is added.
Thirty cases cover non-Org declarations, escape parity, empty cells, CRLF,
Unicode coordinates, EOF, named helper parameters, invalid declarations,
link truncation, adjacent links, recovery scope, overlapping markers and
parent-aware recovery. Boundary controls distinguish literal stops from
matching saved parent names, unrelated closers, unknown parents and explicit
heading/indentation/suffix policies. Invalid declarations fail before execution.
The focused owner requires final OK and rejects harness errors even when a
native test command reports a zero process exit.
The preceding line/link candidate's fresh production build and newly linked
native Org closure pass 178 cases / 12 suites, final OK and the deliberate
exit-42 failure control. =native-boundary-convergence-closure= repeats that
178-case / 12-suite receipt for the boundary candidate, including final OK
and exit-42 negative propagation. The final scoped production build and fresh
=native-scope-convergence-closure= pass 178 cases / 12 suites, final OK and
the exit-42 failure control without OK. Its scope modules are compiled and
linked from the final sources, not substituted with a preceding binary.
These are candidate-path receipts, not exact-head CI or admission
of the unchanged downstream dependency pin.

This closes these algorithms' implementation ownership only. A complete
LineStructure-to-native compiler, complete nesting/recovery,
nested scanner composition, complete state/helper ownership, inline dispatch,
Source coordinate services and native artifact lease ownership remain open.
The existing helper frames isolate invocations. Table, paragraph and link
private state now has explicit rule scopes, with repeated-instance controls;
the remaining helper/domain state and whole-program ownership still require
admission. Language semantic/AOT/FFI and matched
1,000/10,000-document concurrent admission remain consumer responsibilities.
Dependency alignment and existing PR delivery require their own qualification.
