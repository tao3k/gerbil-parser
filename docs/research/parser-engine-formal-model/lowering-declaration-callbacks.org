#+title: Lowering declaration callbacks and construction admission

* Contract and discovered mismatch

The paper's nonterminal vocabulary is not the set of production left-hand
sides. A helper for an empty choice is declared even when it emits no row.
Likewise a reserved undefined reference is not a declaration. The relevant
publication order is augmented owner, authored owners in source order, then
helper callbacks in successful allocation order.

The previous =LoweringProtocol.input= reconstructed declarations from the final
reverse-cons name store. Membership theorems accepted that list even though it
reversed the native helper callback order. This was a model correspondence
defect, not evidence of a native parsing defect or a performance opportunity.
The constructor now consumes explicit callback events. Its membership laws
remain valid, and its ordering is additionally derived rather than assumed.

These callback laws describe the enabled collector used by =lower-grammar=,
not an assertion that an omitted optional =lower-rules= callback executes.

The augmented owner is added separately by =lower-grammar=. Its fallback
=fresh 'accept= is not a helper allocation and must not produce a helper callback.
The native collision matrix checks that separation, including reserved candidate
names. The recursive matrix checks declaration callbacks before proof bindings,
exact order and multiplicity, and the same directory returned by =lower-grammar=.
The failure scenario checks that a rejected declaration callback prevents proof
observation, recursive emission and a normal result.

* Evidence and remaining boundary

=LoweringDeclarations.qnt= exercises nested zero-row calls, callback failure,
omission, reversal, duplication and publication after failure. Its bounded
histories are controls, not the arbitrary-depth proof. Native cases remain in
the original =t/lowering-traversal-test.ss= owner using existing test macros.
The complete original sixteen-owner cold aggregate remains the acceptance gate.

This closes callback projection and collector evaluation for the generated
normal-return protocol. It does not prove the entire actual Scheme dispatcher
simulates that protocol: =case= dispatch, operand mapping, optional proof
closures, arbitrary callback effects and interleaving with production emission
are tracked by the [[file:lowering-scheme-dispatch.org][Scheme dispatch composition]] audit. Its case, map and local closure laws
are now operational; full recursive branch derivation remains open. In particular, source
schema equality alone is not that derivation. Exceptional and nonterminating
callbacks are not claimed to satisfy a returning-execution theorem.

The remaining source simulation must preserve the same cell ownership and
emission ordering rather than assume a complete allocation/callback trace as
input. This obligation belongs to the parser. Reader identity, symbol interning,
compiler execution and host GC behavior remain external premises. Gambit and
SDK sources are neither modified nor built. No runtime optimization follows
from this correspondence repair.
