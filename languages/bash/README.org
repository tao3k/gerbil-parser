#+title: Bash 5.3 source parser

This language directory publishes the preserved Scheme source-parser implementation.
It builds with the normal Gerbil package and exposes a versioned parser entry:

#+begin_src scheme
(import :gerbil-parser/languages/bash/parser)
(parse-bash "printf %s \"${name:-world}\"\n")
#+end_src

The result is a lossless =ParseArtifact=, with structured word/expansion,
assignment, pipeline, compound-command and redirection nodes. Here-document
receipts bind queued markers to body spans. Parsing does not execute shell code
or evaluate expansions.

| Capability | Current evidence |
|---+---|
| Scheme source parser and public entry | 16 native regression cases pass |
| UTF-8 round trips and nested word/parameter syntax | Covered by selected corpus |
| Here-document ordering and compound statements | Covered by selected corpus |
| Complete Bash grammar or editor recovery | Not qualified |
| Canonical Grammar/Parser/Scanner IR | Port remains required |
| Generated pure Rust AOT language | Not supported by this source declaration |
| Standalone native C library / Rust FFI language crate | Packaging remains required |

The descriptor is a =source-language=, not a =LanguageGrammar= generated by
=deflanguage=. Its digest binds the declared language/version/contract labels;
it does not by itself fingerprint the handwritten parser implementation.
Scanner checkpoints are source-bound scan state, not incremental parse reuse
receipts. The release design will additionally bind implementation artifacts
and admit supported backend capabilities explicitly.
