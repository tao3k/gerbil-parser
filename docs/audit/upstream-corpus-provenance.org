#+title: Upstream Corpus Provenance
#+startup: overview

* Immutable sources

The HCL corpus is copied byte-for-byte from HashiCorp HCL =v2.24.0= at commit
=6b5068090eef06b1f127f61529db5ba0be7ed343=.  It contains all 15 raw =.hcl=
inputs under =specsuite/tests=.  HashiCorp HCL is distributed under MPL-2.0.

The GQL corpus is copied byte-for-byte from openGQL grammar =1.9.0= at commit
=16ea71bd320ad07fd2c46a3066afbaef7d226922=.  It contains all 14 =.gql=
files under =samples=.  openGQL grammar is distributed under Apache-2.0.

The openCypher grammar source is copied byte-for-byte from the official
=2024.1= release at commit
=30b451d3b7c94ee5a84a0fdc223947a442dd9493=.  Its 352-production ISO WG3 BNF
file has SHA-256
=c0b5454f001b59b401756158bf88e27847c8ace71f1abc8df1e05f8b710b9f50=.
Macro expansion parses every right-hand side into a structural AST and rejects
digest drift, duplicate production identities, and unresolved references.

The TLA+ grammar oracle is =tree-sitter-tlaplus 1.5.0= at commit
=8a8413f1d08e7ee40b347206d26eac4324db9fd9=.  The executable official source
is =HourClock.tla= from the TLA+ Foundation Examples repository at commit
=ceeaa904140e3e03781cb2a79cd6c6d8b8b08e10=, preserved byte-for-byte with
SHA-256 =985903176db4725f9cf25df84ad84dcd53ba94be80d26298b87ec86fbc9b08b3=.

* Admission invariant

The corpus file path is compilation input only.  Runtime identity is derived
from the embedded source bytes, language version, and v1 contract.

#+begin_src typst
#let H = $"HCLCorpus"_("v2.24.0")$
#let G = $"openGQLCorpus"_("1.9.0")$
#let C = $"openCypherBNF"_("2024.1")$
#let T = $"TLAPlusCorpus"_("1.5.0")$
#let digest(x) = $"sha256"(x)$
$
  |H| = 15 quad and quad |G| = 14 quad and quad |C| = 352 \
  forall f in H union G union T,
    "fixtureDigest"(f) = digest("bytes"(f)) \
  "roundtrip"("parse"(f)) = "bytes"(f) \
  "catalogDigest"(C) = digest("bytes"(C)) \
  partial "fixtureDigest" / partial "absolutePath" = 0
$
#+end_src

The corpus gate proves the complete fixed example sets above.  It does not turn
the example count into a claim of complete language-standard conformance.
